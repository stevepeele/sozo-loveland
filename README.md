# SOZO Loveland — Church Website Rebuild

World-class redesign of https://sozoloveland.com/ — a modern, fast, mobile-responsive church website built with custom code (no page builders).

## Pages (single-page app with smooth-scroll sections)
- **Home** — Hero with vision statement, service times, CTAs
- **About** — Vision (Open / Embrace / Link), Church Values + Leadership Values (tabbed)
- **Ministries** — Kids, Youth, Life Groups, Worship & Arts, Prayer, Outreach, Women, Men
- **Sermons / Media** — Recent sermon archive layout
- **Events** — Sunday service, youth night, life groups
- **Giving** — Generosity section with scripture
- **Visit / Contact** — Address, hours, what-to-expect, contact form

## Design
- Palette: deep navy (#141c2b), warm gold (#c9a86a), cream (#faf7f1)
- Typography: Cormorant Garamond (serif headlines) + Inter (body)
- Scroll-reveal animations, sticky nav, mobile hamburger menu
- Fully responsive, no build step — pure HTML/CSS/JS

## Content migrated from original site
- Vision: "We open our hearts to embrace one another and link together for the kingdom"
- 7 church values, 7 leadership values (with scripture references)
- Address: 9781 Fields Ertel Road, Loveland, OH 45140
- Hours: Mon–Sat 9–5, Sun 9–1

## Deploy
Static site — deploy `index.html` to any static host (Vercel, Netlify, etc.).
